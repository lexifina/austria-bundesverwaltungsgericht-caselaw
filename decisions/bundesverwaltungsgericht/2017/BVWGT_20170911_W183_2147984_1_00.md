Bei einer Simultanhypothek kann das Pfandrecht für dieselbe Forderung zwar auf zwei oder mehreren Liegenschaften bzw. auch auf Liegenschaftsanteilen bestehen (Hinweis OGH 21.12.1995, 3 Ob 138/95), bei Eintragung des Pfandrechts auf verschiedene Miteigentumsanteile derselben Liegenschaft kann aber nicht von einer Simultanhypothek gesprochen werden (Hinweis VwGH 12.01.1978, 2272/77) (VwGH 10.04.2008, Zl. 2007/16/0228).
